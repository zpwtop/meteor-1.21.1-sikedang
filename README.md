# Hachimi + Slime Meteor 独立版 1.0.0 · Minecraft 1.21.1

这个版本只依赖 Meteor Client，不依赖、加载或捆绑 OpenHachimi、SlimefunHelper。
十项功能参考用户上传的 OpenHachimi 与 SlimefunHelper 行为，用 Meteor 事件、设置和 Minecraft 1.21.1 接口重新实现。
它不是 OpenHachimi 全部设置、模式与服务器行为的逐项复刻。

## 安装

使用 Java 21、Minecraft 1.21.1 和 Fabric Loader 0.15.11 或更新版本（启动验证使用 0.16.10）。
在这个游戏实例的 `mods` 文件夹中放入：

1. 用户上传的 `meteor-client-0.5.8.jar`。
2. 本次生成的 `meteor-1.21.1-死氪党-1.0.0.jar`。

**安装时先移除旧独立版和此前的桥接版，只保留一个新版插件 JAR。不要同时安装两个相同 mod ID 的版本。**
下载或重命名时请保留文件名末尾的 **`.jar`**。Windows“类型”应显示 JAR 文件，不能只是“文件”。
此插件不需要 OpenHachimi、SlimefunHelper 或 Fabric API；其他模组自己的依赖请按它们的要求保留。
进入世界，按 Meteor 的菜单按键（默认右 Shift），打开 **Hachimi** 或 **Slime** 分类。

**中文显示：** Meteor 0.5.8 默认自定义字体不包含中文字形。如果列表里只显示 `Hachimi`、`Slime` 而缺少中文，
在 Meteor 菜单顶部打开 **Config → Visual → Custom Font**，将其关闭，即可显示完整中文模块名及说明。
插件不会自动更改你的全局字体偏好。

模块内部名称均按要求保留小写 hachimi 或 slime；Meteor 生成界面标题时会将第一个字母大写。

## 十项功能

| 名称 | 已实现的行为 | 主要设置和要求 |
| --- | --- | --- |
| hachimi自动水晶 | 搜索非好友玩家，对现有水晶和放置位置评分，自动放置、攻击、切换物品并恢复 | 目标距离、放置/攻击距离及间隔、最低目标伤害、最高自身伤害、致命伤害检查、好友保护、预测、转头、使用物品时暂停。水晶放快捷栏或副手；需要现成黑曜石/基岩底座 |
| hachimi自动围住 | SelfTrap：围住自己并封顶 | 黑曜石优先，哭泣黑曜石备用；脚下补块、放置数量、距离、延迟、转头、地面限制、移动停用、居中。这里“围住”解释为围自己，不是围敌人的 AutoTrap |
| hachimi自动围脚 | Surround：围住脚周围，按玩家实际占用范围处理跨格位置 | 黑曜石优先，哭泣黑曜石备用；可双层、补脚下和支撑块，支持距离、延迟、移动停用等设置 |
| hachimi重锤秒切 | 在攻击包发送前切到快捷栏重锤，发送攻击后立即恢复原槽位 | 对应原 MaceSpoof 的切换模式；可忽略水晶、只在下落时工作、设置间隔。重锤放快捷栏 |
| hachimi假飞 | 临时将背包/快捷栏鞘翅与胸甲交换，发送滑翔请求，恢复胸甲，按移动输入控制水平与垂直速度 | 需要有耐久的鞘翅；支持自动起跳、悬停、快捷栏/副手烟花、烟花间隔。打开容器、水中、攀爬或骑乘时暂停；停用时恢复原重力状态 |
| hachimi自动药水 | 自动向脚下扔速度、抗性、力量喷溅药水，随后恢复槽位/背包 | 支持背包交换、间隔、地面限制、效果到期补充；抗性优先 II 及以上。与原版一样，三种效果开关默认关闭，需要自行选择 |

### 本版新增四项

| 名称 | 分类 | 已实现的行为与用法 |
| --- | --- | --- |
| slime甲飞 | Slime | 参考 `ElytraExtra` 的 TICK 甲飞：玩家 tick 前临时穿鞘翅、请求滑翔，tick 后恢复胸甲。先穿胸甲，把有耐久的鞘翅放快捷栏或主背包。支持自动起跳、落地停用、请求间隔 |
| slime简易鞘翅控制 | Slime | 参考 `ElytraFlight` 的 CONTROL / ROTATION 和 VOID / FIRE_WORKS。CONTROL 以 WASD、空格、Shift 控制方向；ROTATION 把前后输入转换到视角方向。VOID 直接控制速度，FIRE_WORKS 转向并使用烟花。支持水平临时无重力、自动前进、落地停用 |
| hachimi发包挖掘 | Hachimi | 对应原版名为 SpeedMine 的模块。生存模式点击一个方块后，松开鼠标仍继续挖掘；使用 Minecraft 的交互序号发开始/完成/取消包，按预计进度在完成时临时切最快工具并恢复。包含范围、进度阈值、等待确认、有限重试、同种方块重放后再挖及进度渲染 |
| hachimi着色器 | Hachimi | 实体模型的纯色/渐变/彩虹填充、点阵、像素描边、外发光；可筛选玩家、自身第三人称、生物、物品、水晶和投射物，调整距离、颜色、透明度、宽度和速度 |

**甲飞 + 简易控制可以配合使用**，也可以穿着鞘翅只开简易控制；不要与原有 `hachimi假飞` 或其他飞行控制同时使用。
简易控制保留原版 VOID 默认速度 **0.05 方块/tick**，觉得慢可在设置中调整。
甲飞会暂停水中、攀爬、骑乘和容器界面中的换装；原版的 LAZY / TICK_LEGACY 模式未移植。
FIRE_WORKS 模式需要快捷栏或副手有烟花，实际推进仍按游戏与服务器规则执行。

发包挖掘目前为**单目标**，不支持原版双挖、Grim/Desync 相关模式；不伪造客户端方块消失，最终以服务器确认的变化为准。

着色器接管 Meteor 的 **CHAMS 实体后处理通道**，停用时恢复之前的通道。请不要同时开启 Meteor 原生 Chams 或其他接管该通道的插件。
当前着色器保留实体本来的纹理并叠加效果；未移植手部着色、容器着色、图像混合和每类实体独立颜色。

药水只选择有效果匹配的喷溅药水，不会喝普通药水，也不会扔滞留药水。
抗性药水可能同时带有缓慢效果（如神龟药水），以游戏物品的实际效果为准。

## 与原版的差异

- 自动水晶实现核心放置/攻击和伤害判断；没有移植 OpenHachimi 的全部放置模式、协议模式、预测细节、线程管理与渲染。
- 围住、围脚不包含原版所有挖掘联动、反挖掘、打水晶和自动补充背包选项。
- 重锤仅实现用户指定的“秒切”。没有加入 MaceSpoof 的位置/高度伪装攻击模式。
- 假飞保留临时换鞘翅与恢复胸甲的思路，控制方式用独立速度设置实现；没有原版的全部 Freeze 模式和其他模块联动。
- 药水未移植原版每种药水的单独快捷键和 Swing 模式，使用 Meteor 模块快捷键与独立效果设置。
- 使用 Meteor 好友系统、模块设置和配置保存，不读取 OpenHachimi 配置。

假飞、重锤和自动放置能否被服务器接受，取决于服务器规则、延迟和服务端实现；本版本不承诺绕过检查。
避免同时启用作用相同的其他战斗/切物品模块，以免重复操作。

## 验证

- 使用用户上传的 Meteor Client 0.5.8 和 Minecraft 1.21.1 + Yarn build.3 编译，输出 Java 21 字节码，并 remap 为 Fabric 生产环境的 intermediary 名称。
- 159 项逻辑检查通过：伤害阈值、致命伤害拒绝、药水效果状态、方向与斜向速度、槽位边界、快捷栏/主背包/胸甲交换，以及成功和异常路径下的恢复。
- 对最终 JAR 的 Minecraft/Meteor 字段和方法引用做静态链接检查；检查无 OpenHachimi / SlimefunHelper 类引用、无原客户端代码打包、无 OpenHachimi/Fabric API 依赖。
- 已在隔离的 Fabric 1.21.1 实例中，仅安装 Meteor 与独立插件，实际启动至主菜单并进入单人世界。
- 通过额外的本地测试辅助模组，验证六个不同生产模块均已注册、可以启用，空背包运行 80 tick 后均可停用，没有插件异常。测试辅助模组不包含在交付 JAR 内；这不验证有装备时的实际攻击/放置效果。
- 真实单人世界验收通过：生存模式用快捷栏钻石镐完成石头发包挖掘，并收到服务器方块移除确认；恢复原手持槽位。
- 甲飞在 49 个玩家 tick 中临时装备主背包第 24 槽的鞘翅，并在每个 tick 后恢复下界合金胸甲与原背包槽位；简易控制停用后恢复原重力状态。
- 实际编译并渲染彩虹/点阵/描边/发光效果；停用时恢复 Meteor 原来的实体后处理通道，再启用仍正常。
- 尚未完成多人服务器及所有设置组合的实战验证。单人验收不等于所有服务器都接受这些行为。

## 从源码构建

需要 Python 3、Java 21 和网络连接；不需要本机安装 Gradle 或 javac。

```sh
python build.py --meteor /完整路径/meteor-client-0.5.8.jar --test
```

脚本会下载固定版本 ECJ、Tiny Remapper、Mixin 编译依赖、Yarn、intermediary 和官方 Minecraft 编译依赖，校验文件哈希，编译、运行检查并生成生产 JAR。
首次下载可能需要一些时间，之后使用 `tools` 缓存。

输出：`dist/meteor-1.21.1-死氪党-1.0.0.jar`。

本插件新增独立源码采用 MIT 授权；Meteor 和 Minecraft 等依赖维持各自授权，源码包不包含它们的 JAR 或反编译代码。
